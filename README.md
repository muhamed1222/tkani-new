# TalkText - Голосовой блокнот

TalkText — это интерактивное веб-приложение для создания и управления текстовыми заметками с помощью голосового ввода. Приложение позволяет пользователям записывать текст голосом или вручную, а затем экспортировать его в популярные форматы документов.

## ✨ Основные возможности

- **🎤 Голосовой ввод** — преобразование речи в текст в реальном времени
- **✏️ Текстовый редактор** — удобный интерфейс для ручного ввода и редактирования
- **📄 Экспорт документов** — сохранение заметок в форматах DOCX и TXT
- **📋 Буфер обмена** — быстрое копирование текста одним кликом
- **🧹 Очистка текста** — мгновенное удаление всего содержимого
- **📱 Адаптивный дизайн** — корректное отображение на всех устройствах

## 🛠️ Установка и запуск

### Предварительные требования
- Node.js 16+ или 18+
- npm 8+ или yarn 1.22+
- Docker и Docker Compose (опционально)
- Микрофон для голосового ввода

### Способ 1: Локальная разработка (рекомендуется)

**Клонирование репозитория**
```bash
git clone https://github.com/IvanZuzichev/TalkText
cd talktext
Установка зависимостей

npm install
# или
yarn install
Запуск в режиме разработки

npm run dev
# или
yarn dev
Открыть в браузере

Приложение будет доступно по адресу: http://localhost:3003

Способ 2: Production сборка
Сборка проекта

npm run build
# или
yarn build
Просмотр production-сборки

npm run preview
# или
yarn preview
Production сборка будет доступна по адресу: http://localhost:3003

Способ 3: Запуск через Docker
Сборка и запуск Docker-контейнера

docker-compose up --build
Приложение будет доступно по адресу: http://localhost:3003

Фоновый режим

docker-compose up -d --build
Остановка контейнера

docker-compose down
Способ 4: Только Docker (без Docker Compose)
Сборка образа

docker build -t talktext-app .
Запуск контейнера

docker run -p 3000:80 --name talktext-container talktext-app
Остановка и удаление

docker stop talktext-container
docker rm talktext-container
📦 Docker команды для управления
# Просмотр запущенных контейнеров
docker ps

# Просмотр образов
docker images

# Просмотр логов
docker logs talktext-app

# Остановка контейнера
docker stop talktext-app

# Удаление контейнера
docker rm talktext-app

# Удаление образа
docker rmi talktext-app

# Очистка системы Docker
docker system prune -a
🔧 Скрипты npm
npm run dev — запуск в режиме разработки
npm run build — сборка для production
npm run preview — предпросмотр production-сборки
npm run lint — проверка кода с ESLint
npm run lint:fix — автоматическое исправление ошибок ESLint
npm run format — форматирование кода с Prettier
```
