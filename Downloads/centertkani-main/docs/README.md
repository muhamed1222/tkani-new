# Центр Ткани - Интернет-магазин тканей

Современный интернет-магазин тканей, разработанный на React с использованием Vite, MobX для управления состоянием и Tailwind CSS для стилизации.

## 🎯 Описание проекта

Интернет-магазин тканей с функционалом:
- Просмотр каталога тканей
- Поиск по товарам
- Корзина покупок
- Личный кабинет пользователя
- Административная панель
- Адаптивный дизайн

## 📦 Требования

Перед установкой убедитесь, что у вас установлены:

- **Node.js** версии 18.0.0 или выше
- **npm** версии 9.0.0 или выше (или **yarn**, **pnpm**)

Проверить версии можно командами:
```bash
node --version
npm --version
```

## 🚀 Установка

1. **Клонируйте репозиторий:**
```bash
git clone https://github.com/muhamed1222/tkani-new.git
cd tkani-new
```

2. **Установите зависимости:**
```bash
npm install
```

Или используйте альтернативные менеджеры пакетов:
```bash
yarn install
# или
pnpm install
```

## ▶️ Запуск проекта

### Режим разработки

Запустите сервер разработки с hot-reload:
```bash
npm run dev
```

Приложение будет доступно по адресу: `http://localhost:5173`

### Сборка для продакшена

Создайте оптимизированную сборку:
```bash
npm run build
```

Собранные файлы будут находиться в папке `dist/`

### Предпросмотр продакшен сборки

Просмотрите собранное приложение локально:
```bash
npm run preview
```

### Проверка кода (Linting)

Запустите ESLint для проверки кода:
```bash
npm run lint
```

### Форматирование кода

Отформатируйте весь код с помощью Prettier:
```bash
npm run format
```

Проверьте форматирование без изменений:
```bash
npm run format:check
```

## 🔄 Lazy Loading

Все компоненты страниц загружаются асинхронно с помощью `React.lazy`:
- Улучшена начальная загрузка приложения
- Компоненты загружаются только при необходимости
- Используется `Suspense` с компонентом `Loading` для отображения состояния загрузки

## 💻 Разработка

### Рекомендации по разработке:

1. **Компоненты**: Создавайте переиспользуемые компоненты в папке `src/components/`
2. **Страницы**: Добавляйте новые страницы в `src/pages/`
3. **Стили**: Используйте CSS Modules для стилей компонентов
4. **Состояние**: Используйте MobX stores для управления состоянием
5. **Маршруты**: Добавляйте новые маршруты в `src/utils/consts.js` и `src/Routes.jsx`

### Работа с MobX:

Stores находятся в `src/store/`:
- `index.js` - централизованная инициализация всех stores (создаются один раз)
- `TkanStore.jsx` - управление данными о тканях, категориях, брендах, баннерах (с кэшированием)
- `UserStore.jsx` - управление состоянием пользователя (использует AuthService и TokenManager)
- `WorksStore.jsx` - управление данными о работах (с кэшированием)

**Важно**: Stores инициализируются один раз в `src/store/index.js` для предотвращения утечек памяти.

### Работа с маршрутизацией:

Маршруты настраиваются в:
- `src/utils/consts.js` - константы маршрутов
- `src/Routes.jsx` - конфигурация публичных и приватных маршрутов
- `src/components/approuter/Approuter.jsx` - логика роутинга

## 🔧 Архитектура и утилиты

### Утилиты

Проект включает централизованные утилиты в `src/utils/`:

- **logger.js** - Условное логирование (только в dev режиме)
- **cache.js** - In-memory кэш с TTL для оптимизации производительности
- **constants.js** - Все константы приложения (таймауты, лимиты, сообщения)
- **cookies.js** - Утилита для работы с cookies
- **errorHandler.js** - Централизованная обработка ошибок
- **validation.js** - Функции валидации данных
- **apiConfig.js** - Конфигурация API URL

### Сервисы

Бизнес-логика вынесена в `src/services/`:

- **AuthService.js** - Логика авторизации и управления профилем
- **TokenManager.js** - Управление токенами авторизации

### Модульная структура API

HTTP запросы организованы в модули (`src/http/`):
- `client.js` - базовый HTTP клиент
- `auth.js` - методы авторизации
- `products.js` - методы для товаров и каталога
- `cart.js` - методы корзины
- `orders.js` - методы заказов
- `admin.js` - методы админки
- `notifications.js` - методы уведомлений
- `contact.js` - методы контактной формы
- `index.js` - централизованный экспорт

## ⚡ Оптимизация производительности

### Кэширование
- Данные категорий, брендов, товаров кэшируются в stores
- TTL (Time To Live) настраивается в `constants.js`
- Автоматическая очистка устаревших записей

### Lazy Loading
- Все компоненты страниц загружаются через `React.lazy`
- Улучшена начальная загрузка приложения

### Оптимизация Re-renders
- Использование `React.memo` для компонентов списков
- `useMemo` и `useCallback` для оптимизации вычислений и функций

## 🔒 Безопасность

- Логирование токенов отключено в production
- Централизованное управление токенами через `TokenManager`
- Улучшенная очистка токенов при logout
