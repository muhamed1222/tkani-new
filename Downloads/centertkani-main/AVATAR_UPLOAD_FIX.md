# Исправление загрузки аватара

## Проблема
Не удавалось загрузить фотографии (аватары) пользователя.

## Исправления

### 1. Исправлена обработка FormData в ApiService
**Проблема:** При отправке FormData устанавливался заголовок `Content-Type`, что мешало браузеру автоматически установить правильный `Content-Type` с boundary.

**Решение:** 
- В `src/http/client.js` добавлена логика, которая удаляет `Content-Type` из заголовков при отправке FormData
- Браузер теперь автоматически устанавливает правильный `Content-Type: multipart/form-data; boundary=...`

### 2. Улучшена обработка ответа от Strapi
**Проблема:** Неправильная обработка разных форматов ответа от Strapi upload endpoint.

**Решение:**
- Добавлена поддержка разных форматов ответа (массив, объект с data)
- Улучшена проверка наличия файла в ответе
- Добавлена проверка наличия file ID

### 3. Улучшена обработка ошибок
**Добавлено:**
- Детальное логирование всех этапов загрузки
- Специфичные сообщения об ошибках для разных HTTP статусов:
  - 401: "Сессия истекла. Пожалуйста, войдите заново."
  - 413: "Файл слишком большой. Максимальный размер: 5MB"
  - 415: "Неподдерживаемый формат файла. Используйте JPG, JPEG или PNG"

### 4. Улучшено логирование
Добавлено логирование:
- Имя файла, размер, тип
- Endpoint для загрузки
- Детали ответа от сервера
- Детали ошибок (статус, сообщение, stack trace)

## Как проверить

1. Откройте консоль браузера (F12)
2. Попробуйте загрузить аватар
3. Проверьте логи в консоли:
   - `Uploading avatar file: [имя файла]`
   - `Uploading file to server: {...}`
   - `File uploaded successfully: [...]`
   - `Uploaded file ID: [id]`
   - `Profile updated with avatar: {...}`

## Возможные проблемы

### Если загрузка все еще не работает:

1. **Проверьте токен авторизации:**
   - Убедитесь, что вы авторизованы
   - Проверьте, что токен не истек

2. **Проверьте формат файла:**
   - Только JPG, JPEG, PNG
   - Максимальный размер: 5MB

3. **Проверьте настройки Strapi:**
   - Endpoint `/api/upload` должен быть доступен
   - Проверьте права на запись в `strapi/public/uploads`
   - Проверьте настройки CORS в Strapi

4. **Проверьте сетевые запросы:**
   - Откройте DevTools → Network
   - Найдите запрос к `/api/upload`
   - Проверьте статус ответа и тело ответа
