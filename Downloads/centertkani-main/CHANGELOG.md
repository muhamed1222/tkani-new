## [Unreleased] - 2025-01-27

### Добавлено

#### Утилиты и сервисы
- **Утилита логирования** (`src/utils/logger.js`)
  - Условное логирование только в режиме разработки
  - Поддержка различных уровней логирования (log, error, warn, info, debug)
  - Автоматическое отключение в production

- **Централизованная обработка ошибок** (`src/utils/errorHandler.js`)
  - Единая система обработки ошибок HTTP запросов
  - Пользовательские сообщения об ошибках
  - Поддержка различных типов ошибок (сетевые, валидация, файлы)

- **Валидация данных** (`src/utils/validation.js`)
  - Функции валидации email, телефона, пароля
  - Валидация файлов (размер, тип)
  - Валидация форм с поддержкой нескольких полей

- **Утилита кэширования** (`src/utils/cache.js`)
  - In-memory кэш с поддержкой TTL (Time To Live)
  - Автоматическая очистка устаревших записей
  - Генерация ключей кэша из параметров

- **Менеджер токенов** (`src/services/TokenManager.js`)
  - Централизованное управление токенами авторизации
  - Работа с localStorage и cookies
  - Синхронизация между хранилищами

- **Сервис авторизации** (`src/services/AuthService.js`)
  - Бизнес-логика авторизации и регистрации
  - Управление профилем пользователя
  - Загрузка и удаление аватара

#### UI Компоненты
- **Компонент Loading** (`src/components/ui/Loading/Loading.jsx`)
  - Единый компонент для отображения загрузки
  - Поддержка различных размеров и тем
  - Fullscreen режим

- **Улучшенная система Toast** (`src/components/ui/Toast.jsx`)
  - Поддержка типов: success, error, warning, info
  - Настраиваемый timeout
  - Использование констант из `constants.js`

#### Константы
- **Файл констант** (`src/utils/constants.js`)
  - Все магические значения вынесены в константы
  - HTTP статус коды
  - Сообщения об ошибках и успехе
  - Таймауты и лимиты
  - TTL для кэширования

### Изменено

#### Рефакторинг архитектуры
- **Модульная структура API** (`src/http/`)
  - Разбит монолитный `api.js` (1000+ строк) на модули:
    - `client.js` - базовый HTTP клиент
    - `auth.js` - методы авторизации
    - `products.js` - методы для товаров и каталога
    - `cart.js` - методы корзины
    - `orders.js` - методы заказов
    - `admin.js` - методы админки
    - `notifications.js` - методы уведомлений
    - `contact.js` - методы контактной формы
    - `index.js` - централизованный экспорт
  - Старый `api.js` реэкспортирует новые модули для обратной совместимости

- **Разделение ответственности в UserStore**
  - Логика авторизации вынесена в `AuthService`
  - Управление токенами вынесено в `TokenManager`
  - UserStore теперь содержит только состояние пользователя

- **Централизованная инициализация stores** (`src/store/index.js`)
  - Stores создаются один раз, не при каждом рендере
  - Исправлена утечка памяти

#### Оптимизация производительности
- **Кэширование данных**
  - Добавлено кэширование в `TkanStore`:
    - Категории (TTL: 1 час)
    - Бренды (TTL: 1 час)
    - Товары (TTL: 15 минут)
    - Баннеры (TTL: 15 минут)
  - Добавлено кэширование в `WorksStore`:
    - Работы (TTL: 15 минут)

- **Lazy loading компонентов** (`src/Routes.jsx`)
  - Все компоненты страниц загружаются через `React.lazy`
  - Добавлен `LazyRoute` с `Suspense` и `Loading` fallback
  - Улучшена начальная загрузка приложения

- **Оптимизация re-renders**
  - `ProductCard`: добавлены `useMemo` и `useCallback` для оптимизации
  - `ProductSection`: обернут в `React.memo` с кастомной функцией сравнения
  - `OrdersList`: обработчики обернуты в `useCallback`
  - Мемоизация вычисляемых значений

#### Безопасность
- **Убрано логирование токенов**
  - Удалено даже частичное логирование токенов
  - Логируется только факт наличия токена

- **Централизованная утилита cookies** (`src/utils/cookies.js`)
  - Единая реализация для работы с cookies
  - Устранено дублирование кода

#### Фильтрация и пагинация
- **Серверная фильтрация товаров**
  - `fetchTkansByCategory` теперь использует серверную фильтрацию
  - Убрана загрузка всех товаров с последующей фильтрацией на клиенте

- **Пагинация товаров**
  - Добавлена поддержка пагинации в `TkanStore`
  - Методы: `loadNextPage()`, `loadPreviousPage()`, `setPageSize()`
  - Состояние: `currentPage`, `pageSize`, `totalPages`, `totalItems`

### Исправлено

- **Утечка памяти в Store**
  - Stores больше не создаются при каждом рендере
  - Централизованная инициализация в `src/store/index.js`

- **Дублирование кода**
  - Утилита cookies вынесена в отдельный модуль
  - Унифицирована конфигурация API URL
  - Единый обработчик ошибок

- **Производительность**
  - Исправлена клиентская фильтрация (перенесена на сервер)
  - Убраны лишние перерисовки компонентов
  - Оптимизированы списки товаров

### Удалено

  - Заменены на использование `logger` утилиты
  - 342 вхождения в 26 файлах

### Технические улучшения

- **ESLint конфигурация**
  - Добавлено правило запрета `console.*` в production
  - Правила для React hooks
  - Правила для лучших практик
