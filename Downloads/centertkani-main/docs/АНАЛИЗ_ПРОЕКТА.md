# 📊 Полный анализ проекта "Центр Ткани"

## 🎯 Общее описание

**Проект**: Интернет-магазин тканей "Центр Ткани"  
**Архитектура**: Full-stack приложение с разделением на фронтенд и бэкенд  
**Статус**: Разработан, в стадии разработки/поддержки

---

## 🏗️ Архитектура проекта

Проект состоит из двух основных частей:

### 1. **Фронтенд** (`tkani-new`)
- **Технология**: React 19.1.1 + Vite 7.1.7
- **Управление состоянием**: MobX 6.15.0
- **Маршрутизация**: React Router DOM 7.9.5
- **Стилизация**: Tailwind CSS 3.4.17 + CSS Modules
- **UI библиотеки**: Radix UI Themes, Bootstrap 5.3.8

### 2. **Бэкенд** (`tkani-new-back-strapi`)
- **CMS**: Strapi (headless CMS)
- **База данных**: Настраивается через конфигурацию
- **API**: RESTful API на основе Strapi

## 🌐 API интеграция

### Конфигурация:
- Базовый URL: настраивается через переменные окружения
- `VITE_API_URL` - URL API (по умолчанию: `http://localhost:1339/api`)
- `VITE_STRAPI_URL` - URL Strapi (по умолчанию: `http://localhost:1337`)

### API сервисы (`src/http/api.js`):

1. **catalogAPI** - каталог товаров
   - `getProducts()` - получить товары
   - `getProduct(id)` - получить товар по ID
   - `getCategories()` - получить категории
   - `getCatalogSections()` - получить разделы каталога
   - `getBrands()` - получить бренды
   - `getBanners()` - получить баннеры

2. **authAPI** - аутентификация
   - `login()` - вход
   - `register()` - регистрация
   - `checkAuth()` - проверка авторизации
   - `updateProfile()` - обновление профиля
   - `changePassword()` - смена пароля
   - `forgotPassword()` - восстановление пароля
   - `resetPassword()` - сброс пароля
   - `deleteAccount()` - удаление аккаунта

3. **cartAPI** - корзина
   - `getCart()` - получить корзину
   - `addToCart()` - добавить в корзину
   - `updateCart()` - обновить корзину
   - `removeFromCart()` - удалить из корзины
   - `clearCart()` - очистить корзину

4. **ordersAPI** - заказы
   - `createOrder()` - создать заказ
   - `getMyOrders()` - получить заказы пользователя
   - `getOrder(id)` - получить заказ по ID

5. **adminAPI** - административная панель
   - Управление товарами (CRUD)
   - Управление категориями
   - Управление брендами
   - Управление заказами
   - Управление пользователями
   - Управление работами
   - Статистика

6. **worksAPI** - работы (портфолио)
   - `getAll()` - получить все работы
   - `getById(id)` - получить работу по ID

7. **notificationsAPI** - уведомления
   - `getNotifications()` - получить уведомления
   - `markAsRead()` - пометить как прочитанное
   - `getUnreadCount()` - количество непрочитанных

8. **contactAPI** - контактная форма
   - `sendMessage()` - отправить сообщение
